# 专注栖所 · Focus Core

一个安静、轻量的浏览器专注计时工具。

专注栖所不把你拉进复杂的任务管理流程，而是把注意力放回当下：点击一下，开始一段专注；每完成一分钟，专注记录就会被安静地收拢。随着时间留下记录，你可以看到今天、本周和长期的专注成果，也能在专注日历中回望那些认真投入过的日子。

## 主要特点

- **一键开始，随时暂停**：支持开始、暂停和继续，计时状态会自动保存，刷新页面后也能尽量恢复当天的进度。
- **专注状态反馈**：开始专注后，中央环境光会柔和增强并呼吸变化；暂停后回到安静状态，不打扰当前节奏。
- **专注数据一目了然**：实时查看今日专注、本周专注、累计专注和连续专注天数。
- **本周目标提醒**：中央显示距离本周 35 小时目标还需投入的时间，达标后安静隐藏。
- **可交互专注日历**：按月查看日期，颜色深浅记录专注密度；备注直接显示在日期下方，悬停可查看详情，点击日期即可轻量编辑。
- **本地优先，更注重隐私**：数据保存在当前浏览器的 `localStorage` 中，不需要注册账号，也不依赖后端服务。
- **数据可控**：设置中可以导出累计专注时间和日历记录的 JSON 数据，也可以一键清除本地记录。
- **轻盈但不简陋**：响应式布局适配桌面和移动端；动画会根据专注状态变化，并支持系统的“减少动态效果”偏好。
- **没有多余打扰**：没有广告、社交榜单和复杂配置，打开页面就能开始专注。

## 如何使用

### 直接使用

本项目是纯前端静态页面，不需要安装依赖或执行构建：

1. 在浏览器中打开项目根目录下的 `index.html`。
2. 点击中间的“进入专注”开始计时。
3. 需要休息时点击按钮暂停，准备好后再次点击继续。
4. 点击右上角设置按钮，可以导出数据或清除本地数据。

如果浏览器对 `file://` 页面限制了本地存储，建议使用下面的本地服务器方式。

### 使用本地服务器

在项目根目录执行：

```bash
python -m http.server 8000
```

然后访问 [http://localhost:8000](http://localhost:8000)。

## 计时与数据规则

- 只有完整完成的分钟才会计入统计。
- 今日、本周、累计时长和连续天数会随着专注记录自动更新。
- 本周专注时间按周一至周日计算，并在下一个周一凌晨重置；剩余时间按 `2100 - weeklyFocusMinutes` 计算，达到或超过 2100 分钟后，中央提醒淡出并隐藏。
- 专注日历按月展示，日记录仍保留最近 365 天；日历编辑以 `focusMinutes` 与 `note` 为主，旧数据中的 `deadline` 字段会继续保留并兼容读取，但不在日历界面展示。
- 数据只保存在当前浏览器和当前用户配置中。清理浏览器站点数据、更换浏览器或更换设备，都可能导致数据不可见；重要记录建议及时导出。

## 本地开发与测试

项目没有打包工具，HTML、CSS 和 JavaScript 文件可以直接阅读和修改。核心逻辑按功能拆分在 `js/` 目录中，适合快速学习、二次定制或嵌入其他静态页面。

运行全部测试：

```bash
node --test
```

当前测试覆盖计时与数据同步、中央目标提醒、热力图更新、动效控制和格式化逻辑等关键行为。

## 项目结构

```text
.
├─ index.html              # 页面结构
├─ css/style.css           # 视觉样式、响应式布局与动效
├─ js/
│  ├─ app.js               # 页面协调与生命周期
│  ├─ timer.js             # 专注计时状态机
│  ├─ storage.js           # 本地数据读写与迁移
│  ├─ statistics.js        # 日/周/累计统计与连续天数
│  ├─ heatmap.js           # 按月专注日历、tooltip 与日期编辑
│  ├─ focus-motion.js      # 专注状态动效控制
│  ├─ settings.js          # 导出与清除数据
│  └─ formatters.js        # 时长和天数格式化
├─ assets/                 # Logo 与 favicon
└─ tests/                  # Node 原生测试
```

## 适合谁

如果你想要一个不喧闹、不强迫你制定复杂计划，只负责陪你专心一会儿的工具，专注栖所会是一个很轻的起点。它把“完成任务”变成“守住当下”，把每天不起眼的几分钟，慢慢汇聚成一束看得见的光。
