# 专注栖所 · Focus Core

一个安静、轻量的浏览器专注计时工具。

专注栖所不把你拉进复杂的任务管理流程，而是把注意力放回当下：点击一下，开始一段专注；每完成一分钟，专注记录就会被安静地收拢。随着时间留下记录，你可以看到今天、本周和长期的专注成果，也能在专注日历中回望那些认真投入过的日子。

## 主要特点

- **一键开始，随时暂停**：支持开始、暂停和继续，计时状态会自动保存，刷新页面后也能尽量恢复当天的进度。
- **专注状态反馈**：暖白与松绿构成明亮的专注空间；计时器置于中央光环内，开始时光环增强并流转，暂停后圆环停留。
- **专注数据一目了然**：实时查看今日专注、本周专注、累计专注和连续专注天数。
- **本周目标提醒**：计时器下方显示本周 30 小时目标的进度和剩余时间，达标后呈现完成提示。
- **可交互专注日历**：按月查看日期，颜色深浅记录专注密度；备注直接显示在日期下方，悬停可查看详情，点击日期即可轻量编辑。
- **本地优先，更注重隐私**：数据保存在当前浏览器的 `localStorage` 中，不需要注册账号，也不依赖后端服务。
- **数据可控**：设置中可以导出累计专注时间和日历记录的 JSON 数据，也可以一键清除本地记录。
- **轻盈但不简陋**：响应式布局适配桌面和移动端；静态晨光背景减少持续渲染，专注时保留圆环动画，并支持系统的“减少动态效果”偏好。
- **没有多余打扰**：没有广告、社交榜单和复杂配置，打开页面就能开始专注。

## 如何使用

### 直接使用

本项目是纯前端静态页面，不需要安装依赖或执行构建：

1. 在浏览器中打开项目根目录下的 `index.html`。
2. 点击“开始一段专注”。中央显示本段已专注时长，持续计时，直到手动点击“结束本段”。
3. 时间不准确时，直接点击中央数字，在滚轮中调整小时、分钟、秒并保存。支持拖动、惯性滚动、鼠标滚轮和方向键；取消或按 Escape 不修改记录。
4. 点击右上角设置按钮，可以导出、导入 JSON 或清除本地数据。导入时选择此前导出的 JSON 文件，即可替换累计时长、日历备注和专注片段，页面会立即更新。请先结束当前专注；导入前会自动将完整原数据备份至浏览器的 `focus-core.before-import` 存储项（保留最近一次），文件格式错误或保存失败不会覆盖原记录。导入的未结束片段仅保留已计入的时长，不会自动继续计时。
5. 页面不再显示专注片段列表；已有记录继续用于统计和导出。需要修正当前时长时，直接点击中央计时数字。

### 防漏记规则

- 滚轮直接修改本段有效专注时长并同步增减统计，不移动起止时间，也不检查时间重叠。运行中的片段从修正值继续计时，不会自动暂停；修正值会随记录保存和导出。
- 暂停的片段保留结束时间并保持暂停；还没有片段时，保存会补记一段截至现在的记录。重复保存不会重复累计。
- 开始时间随记录保存；后台、休眠或关闭页面后重新打开，会补算离开期间的时间，直到手动结束。
- 需要休息时手动点击“结束本段”。忘记结束时，可通过滚轮修正有效专注时长。
- 旧版正在运行的计时会先暂停，已统计时长保留；未知离开时间不自动补算，可点击中央数字修正。
- 滚轮可将当前有效时长调整为 1 秒到 23 小时 59 分 59 秒，不进行时间重叠检查。
- 旧版只有每日总量，没有真实起止时间，因此保留累计但不生成片段。新片段与旧总量之间的实际时间重叠无法自动判断。

如果浏览器对 `file://` 页面限制了本地存储，建议使用下面的本地服务器方式。

### 使用本地服务器

在项目根目录执行：

```bash
python -m http.server 8000
```

然后访问 [http://localhost:8000](http://localhost:8000)。

## 计时与数据规则

- 每段只有完整完成的分钟才会计入统计；跨午夜的完整分钟按该分钟开始时所在日期归属。
- 今日、本周、累计时长和连续天数会随着专注记录自动更新。
- 本周专注时间按周一至周日计算，并在下一个周一凌晨重置；剩余时间按 `1800 - weeklyFocusMinutes` 计算，达到或超过 1800 分钟后，中央提醒淡出并隐藏。
- 专注日历按月展示，日记录仍保留最近 365 天；日历编辑以 `focusMinutes` 与 `note` 为主，旧数据中的 `deadline` 字段会继续保留并兼容读取，但不在日历界面展示。
- 数据只保存在当前浏览器和当前用户配置中。清理浏览器站点数据、更换浏览器或更换设备，都可能导致数据不可见；重要记录建议及时导出。

## 本地开发与测试

项目没有打包工具，HTML、CSS 和 JavaScript 文件可以直接阅读和修改。核心逻辑按功能拆分在 `js/` 目录中，适合快速学习、二次定制或嵌入其他静态页面。

运行全部测试：

```bash
node --test
```

当前测试覆盖计时与数据同步、中央目标提醒、热力图更新、动效控制和格式化逻辑等关键行为。

### 性能策略

- 背景渐变保持静态，移除计时器多层模糊流动装饰；闲置和暂停时圆环停止旋转。
- 每秒计时仅复制单个片段，当前片段与最近片段的索引随数据修改失效，避免反复序列化全部历史记录和排序。
- 片段计时复用每秒刷新进行分钟结算，不再同时启动另一条分钟结算定时器；后台仍停止刷新，返回时补算至当前时间。
- 每日维护仅在前台安排；切到后台时取消，返回前台时先处理跨日统计，再安排下一次午夜维护。后台初次打开也不启动每日维护任务。
- 回归测试包含 1 万条历史片段下的连续计时读取，以及索引在修改、删除、清空后的正确性。

### Windows 进程实测

在浏览器任务管理器中确认页面的进程 ID，将页面切到后台后，在 PowerShell 中运行（将 `12345` 替换为实际 ID）：

```powershell
./tests/Measure-PageProcess.ps1 -TargetProcessId 12345 -DurationSeconds 180 -IntervalSeconds 5
```

脚本只读操作系统计数器，在 `tests/performance-results/` 保存逐次 CSV 和汇总 JSON。CPU 同时报告单个逻辑核心及全机口径；物理工作集和私有提交内存均以 MiB 表示，不能等同于 JavaScript 堆。脚本不会自动切换标签页，采样时需保持目标页面在后台；同一渲染进程若承载其他页面，结果也包含它们的开销，不包含独立 GPU 进程。进程退出或 ID 被复用时中止并保存已有样本。

```text

│  ├─ heatmap.js           # 按月专注日历、tooltip 与日期编辑
│  ├─ focus-motion.js      # 专注状态动效控制

├─ assets/                 # Logo 与 favicon
```

## 适合谁

如果你想要一个不喧闹、不强迫你制定复杂计划，只负责陪你专心一会儿的工具，专注栖所会是一个很轻的起点。它把“完成任务”变成“守住当下”，把每天不起眼的几分钟，慢慢汇聚成一束看得见的光。
